# EduSphere (new design prototype)

A clickable prototype of the redesigned EduSphere school management app. It keeps every feature of the current EduFlow app, with a friendlier and more accessible interface.

## Run it

Open `index.html` in any browser. No install or internet needed. All data is sample data kept in memory.

## Demo logins

- Parent: student code `AARAV-6A`
- Teacher: school code `TISK-2026`
- Principal: any email, or use the demo button

## Features

- **Parent:** dashboard, attendance calendar, homework tick-off, class diary, timetable, exam schedule, marks, printable report card, leave requests, messages, announcements, PTM slot booking, notifications
- **Teacher:** mark and edit attendance with approval, homework, diary, timetable, enter marks and results, student progress, leave review, messages, announcements, PTM, substitute log
- **Principal:** overview, analytics, class comparison, unapproved absences, approvals, manage teachers/classes/students/subjects, timetable editor, exams, reports (CSV), settings

## Accessibility

Text size controls, high-contrast mode, light and dark themes, keyboard navigation, skip link, large touch targets and reduced-motion support.

## Files

- `index.html` page shell
- `style.css` design system and themes
- `data.js` sample data and helpers
- `ui.js` state, sign-in and app shell
- `pages.js` all screens
- `app.js` actions, forms and events
